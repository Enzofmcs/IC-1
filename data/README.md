# Tabelas fornecidas pelo autor

`source_tables/` contém transcrições de observações dos arquivos adicionais. Os CSVs VIN mantêm todas as 74 linhas e sete colunas instrumentais. Os espectros foram transcodificados para UTF-8 sem alterar os valores textuais e preservam o desvio-padrão. A série IMT/SRF é suplementar e não tem identificação química confirmada.

`reference/` contém valores de planilhas históricas derivadas, usados para conferir a reprodução. `results/` na raiz contém os resultados da nova conferência. Nenhum arquivo original foi sobrescrito.
